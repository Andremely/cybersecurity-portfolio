# 🛡️ Cybersecurity Portfolio

This repository documents my hands-on technical labs, projects, and practical exercises in networking, defensive security, traffic analysis, threat monitoring, and automation as part of my career transition into cybersecurity.

## 📂 Portfolio Structure

* **`01-networking-and-systems/`** 
  * Cisco Packet Tracer labs, LAN topology design, DHCP configuration, Access Control Lists (ACLs), and MAC filtering.
* **`02-defensive-security/`** 
  * Firewall rule configurations, Intrusion Detection Systems (IDS), and Intrusion Prevention Systems (IPS).
* **`03-analysis-and-monitoring/`** 
  * Network scanning and active reconnaissance using **Nmap**, packet capture and traffic analysis with **Wireshark**, and log analysis & threat detection in **Splunk**.
* **`04-python-automation/`** 
  * Basic Python scripts for security tasks and operational support.
