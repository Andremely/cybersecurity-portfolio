# 📂 03. Analysis and Monitoring

This section covers active reconnaissance, packet analysis, and log monitoring using industry-standard security tools.

## 🛠️ Topics & Labs Covered:
* **Nmap Scanning:** Host discovery, port scanning, service enumeration, and OS detection.
* **Wireshark Traffic Analysis:** Deep packet inspection, TCP handshake analysis, and identifying suspicious traffic.
* **Splunk SIEM:** Log ingestion, searching, creating dashboards, and basic threat detection rules.
